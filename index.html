Политика конфиденциальности приложения «Копилка жизни»

Дата последнего обновления: 17 сентября 2026 г.

1. Общие положения

Настоящая Политика конфиденциальности (далее — «Политика») описывает, какие данные собирает мобильное приложение «Копилка жизни» (далее — «Приложение»), как они используются, где хранятся и какие права есть у пользователя.

Используя Приложение, вы соглашаетесь с условиями настоящей Политики.

Разработчик: самозанятый Красников Александр Игоревич
Контактный email: infoprilo85@gmail.com

2. Какие данные собирает Приложение

Приложение собирает и обрабатывает следующие данные:

2.1. Данные, которые вводит пользователь:

  • Имя пользователя (для отображения в интерфейсе и названия папки архива)
  • Email-адреса доверенных контактов (для отправки приглашений)
  • Ссылка на облачную папку (для доступа контактов к архиву)

2.2. Данные, которые создаёт пользователь в процессе использования:

  • Фотографии (при выполнении заданий)
  • Видеозаписи (при выполнении заданий)
  • Голосовые записи (при выполнении заданий)
  • Текстовые комментарии (обязательные к каждой записи)
  • Изображения с текстом (PNG-картинки, создаваемые Приложением из текста)

2.3. Технические данные:

  • Язык интерфейса (выбранный пользователем)
  • Настройки уведомлений (время, вкл/выкл)
  • Настройки фоновой музыки (вкл/выкл)
  • Путь к выбранной облачной папке

3. Как используются данные

Все данные используются исключительно для работы Приложения:

  • Имя — для отображения в интерфейсе и формирования названия папки архива.
  • Email контактов — для отправки приглашений (только по инициативе пользователя).
  • Фото, видео, голос, текст — для сохранения в архив и отображения в календаре.
  • Настройки — для корректной работы уведомлений, музыки и языка.

Приложение не передаёт данные третьим лицам. Данные не используются для рекламы, аналитики или маркетинга.

4. Где хранятся данные

4.1. Локально на устройстве:

Все записи (фото, видео, голос, текст) хранятся в защищённой папке Приложения на вашем устройстве.

4.2. В облачном хранилище (по выбору пользователя):

Пользователь может выбрать облачную папку (Google Drive, Яндекс.Диск, Dropbox и т.д.), куда Приложение сохраняет копию архива. Доступ к этой папке регулируется правилами выбранного облачного сервиса.

4.3. Локальные настройки:

Настройки (язык, уведомления, музыка, контакты, ссылка на папку) хранятся в защищённом хранилище устройства (AsyncStorage).

5. Кто имеет доступ к данным

  • Пользователь — полный доступ ко всем своим данным.
  • Доверенные контакты — доступ к архиву только в случае, если пользователь долго не выходил на связь и если он сам указал ссылку на облачную папку.
  • Разработчик — не имеет доступа к данным пользователя. Все данные хранятся на устройстве пользователя или в его личном облаке.

6. Разрешения, которые запрашивает Приложение

  • Камера — для создания фото и видео.
  • Микрофон — для записи голосовых заданий.
  • Галерея — для выбора фото/видео из галереи.
  • Уведомления — для напоминаний о заданиях в 9:00 и 19:00.
  • Доступ к папке — для сохранения архива в облако.

Все разрешения запрашиваются только при необходимости и могут быть отозваны пользователем в настройках телефона.

7. Уведомления

Приложение отправляет локальные уведомления в 9:00 и 19:00, если задание на день не выполнено. Уведомления можно отключить в настройках Приложения.

8. Фоновая музыка

Приложение воспроизводит фоновую музыку во время работы. Музыка останавливается при сворачивании Приложения. Её можно отключить в настройках.

9. Дети

Приложение не предназначено для детей младше 6 лет. Мы не собираем данные детей сознательно.

10. Безопасность

Мы принимаем разумные меры для защиты данных:

  • Данные хранятся в защищённой папке Приложения.
  • Передача данных в облако происходит по защищённому соединению (HTTPS).
  • Приложение не содержит рекламы и трекеров.

Однако ни один метод передачи данных через интернет не является абсолютно безопасным. Мы не можем гарантировать 100% защиту, но делаем всё возможное.

11. Права пользователя

Вы имеете право:

  • Удалить все данные — через настройки Приложения или удалив Приложение.
  • Отозвать разрешения — в настройках телефона.
  • Отключить уведомления — в настройках Приложения.
  • Запросить информацию о том, какие данные хранятся — по email.

12. Изменения в Политике

Мы можем обновлять эту Политику. При существенных изменениях — уведомим через Приложение. Дата последнего обновления указана в начале документа.
