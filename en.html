Privacy Policy of the "Life Piggy Bank" Application

Last updated: September 17, 2026

1. General Provisions

This Privacy Policy (hereinafter referred to as the "Policy") describes what data the mobile application "Life Piggy Bank" (hereinafter referred to as the "Application") collects, how it is used, where it is stored, and what rights the user has.

By using the Application, you agree to the terms of this Policy.

Developer: self-employed Krasnikov Alexander Igorevich
Contact email: infoprilo85@gmail.com

2. What Data the Application Collects

The Application collects and processes the following data:

2.1. Data entered by the user:

  • User name (for display in the interface and naming the archive folder)
  • Email addresses of trusted contacts (for sending invitations)
  • Link to a cloud folder (for contacts to access the archive)

2.2. Data created by the user during use:

  • Photos (when completing tasks)
  • Videos (when completing tasks)
  • Voice recordings (when completing tasks)
  • Text comments (mandatory for each entry)
  • Images with text (PNG images generated by the Application from text)

2.3. Technical data:

  • Interface language (selected by the user)
  • Notification settings (time, on/off)
  • Background music settings (on/off)
  • Path to the selected cloud folder

3. How Data Is Used

All data is used exclusively for the operation of the Application:

  • Name — for display in the interface and forming the archive folder name.
  • Contact emails — for sending invitations (only at the user's initiative).
  • Photos, videos, voice, text — for saving to the archive and displaying in the calendar.
  • Settings — for the correct operation of notifications, music, and language.

The Application does not transfer data to third parties. Data is not used for advertising, analytics, or marketing.

4. Where Data Is Stored

4.1. Locally on the device:

All entries (photos, videos, voice, text) are stored in a secure folder of the Application on your device.

4.2. In cloud storage (at the user's choice):

The user may choose a cloud folder (Google Drive, Yandex.Disk, Dropbox, etc.) where the Application saves a copy of the archive. Access to this folder is governed by the rules of the selected cloud service.

4.3. Local settings:

Settings (language, notifications, music, contacts, folder link) are stored in the device's secure storage (AsyncStorage).

5. Who Has Access to the Data

  • The user — full access to all their data.
  • Trusted contacts — access to the archive only if the user has not been in touch for a long time and only if the user themselves provided the cloud folder link.
  • The developer — does not have access to the user's data. All data is stored on the user's device or in their personal cloud.

6. Permissions Requested by the Application

  • Camera — for creating photos and videos.
  • Microphone — for recording voice tasks.
  • Gallery — for selecting photos/videos from the gallery.
  • Notifications — for task reminders at 9:00 AM and 7:00 PM.
  • Folder access — for saving the archive to the cloud.

All permissions are requested only when necessary and can be revoked by the user in the phone settings.

7. Notifications

The Application sends local notifications at 9:00 AM and 7:00 PM if the daily task has not been completed. Notifications can be disabled in the Application settings.

8. Background Music

The Application plays background music during operation. The music stops when the Application is minimized. It can be disabled in the settings.

9. Children

The Application is not intended for children under 6 years of age. We do not knowingly collect data from children.

10. Security

We take reasonable measures to protect data:

  • Data is stored in a secure folder of the Application.
  • Data transfer to the cloud occurs over a secure connection (HTTPS).
  • The Application contains no advertising or trackers.

However, no method of transmitting data over the internet is absolutely secure. We cannot guarantee 100% protection, but we do our best.

11. User Rights

You have the right to:

  • Delete all data — through the Application settings or by deleting the Application.
  • Revoke permissions — in the phone settings.
  • Disable notifications — in the Application settings.
  • Request information about what data is stored — by email.

12. Changes to the Policy

We may update this Policy. In case of significant changes, we will notify you through the Application. The date of the last update is indicated at the beginning of the document.
